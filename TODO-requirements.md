Bank Hapoalim Challenge:  Chat with Bot

# 🎯 Task

Implement a chat application where you and your friends can post questions & answers in a chat room. we would like you to include a special member in the room - an awesome bot which should answer questions.
The bot should have global knowledge and act as a senior frontend web development, with expert knowledge in angular.
Every time a person in the chat, ask a question about web development, the bot will wake up and response to this question.
We would appreciate a bot with a unique personality - an entertaining AI experience. (chat room + bot).

# ⚙️ REQUIREMENTS

1. The application should be a single page app which should focus on the
   chat room itself (without authentication, etc.).

2. Implement the user interface using Angular and the server-side functionality using Node.js, build the workspace with MONOREPO NX (use the libs options).

* You are allowed to use any additional libraries.

## ❗ PAY ATTENTION TO

1. Synchronization - How will you architect a chat room that is fully synchronized the client and the server?

2. Beautiful UI - you are welcome to use any library you want.
   (For example and inspiration: Dribbble and Codepen)
   as well as taking inspiration from everyday chats apps.

3. Code Structure & Edge Cases - Think about how to structure the code to be robust and something you would be proud to present to us.
   Apply clean architecture principles, separating business logic into services.

4. Core functionality - This is the essence of the challenge! Creating a bot with a good personality.

5. Performance- Implement performance considerations (e.g., lazy loading, change detection optimization). Employing other techniques to improve application responsiveness.
6. Code Quality - Comprehensive unit tests using Jest. Only where you think it is a critical component or flow to cover.

7. Documentation – write extensive documentation for the application and its components (you can use Ts Docs)

8. Deploy - showcasing its functionality and provide a valid deployment link (you can use Railway or any other deployment options)

# 💰 BONUS

1. Ensure responsiveness across different screen sizes
   and demonstrate consideration for accessibility (A11y).
2. Implement subtle animations for transitions and feedback. Unique features beyond chatting (e.g., quick reactions, editing and history).
3. Encourage the use of cutting-edge web APIs and modern standards.
